# Prime Number Checker

## Explanation

This program determines whether a given positive integer is a prime number.

## Problem Statement

Write a Python program to check whether a number is divisible only by 1 and itself.

## Features

* Checks prime numbers
* Handles numbers less than 2
* Uses efficient divisor checking
* Simple user interface

## How It Works

1. Read a number.
2. Check numbers from 2 up to the square root.
3. If a divisor is found, the number is not prime.
4. Otherwise, the number is prime.
